HTML + CSS - Теория для начинающих

Что такое HTML?

HTML (HyperText Markup Language) — это язык разметки текста и гипертект. С помощью HTML создаётся структура веб-страницы.

Заголовки

<h1></h1> — заголовок самый главный. Существует 6 уровней: от h1 до h6.

h1 - Главный заголовок

h2 - Второстепенный

h3 - Третий уровень

Подсказка: набрав ! в пустом html-файле, редактор сам напишет базовый код страницы.

Параграфы

<p></p> — тег для создания параграфов (абзацев текста).

Это первый параграф текста.

А это второй параграф. Каждый из них отделён отступами.

Что такое тег?

Тег — это < и >. Например: <p>.

Открывающий тег выглядит как <p>, а закрывающий — как </p> (со слэшем).

Большинство тегов парные: открывающий + закрывающий.

Строчный и блочный элементы

<span></span> — строчный элемент. Не переносит строку, идёт в одну линию.

Это строчный: СПАН СПАН СПАН — все в одну строку.

<div></div> — универсальный блочный контейнер. Занимает всю ширину и переносит строку.

Это блок 1
Это блок 2
Это блок 3

Списки

<li></li> — элементы списка.

<ol></ol> — порядковый (нумерованный) список.

<ul></ul> — неупорядочный (маркированный) список.

Неупорядочный список (ul)

  • Пункт первый
  • Пункт второй
  • Пункт третий

Порядковый список (ol)

  1. Пункт первый
  2. Пункт второй
  3. Пункт третий

Ссылки и атрибуты

<a href="ссылка"></a> — создаёт ссылку.

Перейти по ссылке (откроется в новой вкладке)
Атрибуты всегда находятся в открывающем теге. Например: <a href="..."> — атрибут href стоит в открывающем теге.

Символ # означает, что это якорь — ссылка на часть страницы, а не на внешний адрес. Например: <a href="#top">.

Изображения

<img src="..." alt="..."> — вставляет картинку.

Атрибут alt — текст, который показывается, если изображение не загрузилось, и для исключения/доступности (незрячие пользователи).
<img src="photo.jpg" alt="описание фото">

Подвал сайта

<footer></footer> — подвал (нижняя часть) сайта. Обычно содержит копирайт и контакты.
